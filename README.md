# 給与計算・年末調整システム（PWA版セットアップ手順）

このフォルダには、GitHub Pagesで公開してPC・スマホにインストール（PWA化）するために
必要なファイル一式が入っています。

```
pwa-package/
├── index.html          … アプリ本体（年度選択機能つき・令和8年分ベース）
├── manifest.json        … PWAの設定ファイル（アプリ名・アイコン・色など）
├── service-worker.js    … オフライン対応・キャッシュ管理
├── icons/
│   ├── icon-192.png            … プレースホルダーアイコン（後で差し替え可）
│   ├── icon-512.png
│   ├── icon-512-maskable.png
│   └── apple-touch-icon.png
└── README.md            … このファイル
```

## 1. 事前にやっておくこと：今のデータをバックアップ

今 `file://` で使っているアプリ（`給与計算アプリ_令和8年分_35_1.html` など）の
「データのバックアップ」ページから **JSONを書き出しておいてください**。
GitHub Pagesで公開すると、これまで使っていたページとは別サイト（別オリジン）
扱いになり、ブラウザに保存されているデータは自動的には引き継がれません。
新しいURLでアプリを開いた後、同じ「データのバックアップ」ページから
このJSONを読み込めば、全データを復元できます。

## 2. GitHubリポジトリを新規作成する

1. GitHub（https://github.com）にログインし、右上の「＋」→「New repository」
2. リポジトリ名を決める（例：`payroll-app`）。**Public**（公開）にしてください
   （GitHub Pagesの無料利用にはPublicリポジトリが基本です。有料プランならPrivateでも可）
3. 「Create repository」をクリック

## 3. ファイルをアップロードする

作成したリポジトリのページで、
1. 「Add file」→「Upload files」
2. このフォルダの中身（`index.html`、`manifest.json`、`service-worker.js`、
   `icons`フォルダごと）をすべてドラッグ＆ドロップ
   - フォルダごとドラッグすればディレクトリ構成はそのまま保たれます
3. 下の「Commit changes」をクリック

（GitやGitHub Desktop、他のチャットで使っているコマンドライン操作に慣れていれば、
`git add . && git commit -m "PWA対応版を追加" && git push` でも構いません。）

## 4. GitHub Pagesを有効にする

1. リポジトリの「Settings」タブ →左メニューの「Pages」
2. 「Build and deployment」の「Source」で **Deploy from a branch** を選択
3. Branch を `main`（または `master`）、フォルダを `/ (root)` にして「Save」
4. 数十秒〜数分待つと、ページ上部に公開URLが表示されます
   （例：`https://ユーザー名.github.io/payroll-app/`）

## 5. スマホ・PCにインストールする

公開URLをブラウザで開いたら：

- **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：右上の「⋮」メニュー →「アプリをインストール」
  （自動でインストールバナーが出ることもあります）
- **Windows/Mac（Chrome・Edge）**：アドレスバー右側のインストールアイコン
  （＋つきの画面アイコンなど）をクリック→「インストール」

インストール後は、ホーム画面やスタートメニューから
ブラウザのアドレスバー無しの単独アプリのような見た目で起動できます。

## 6. データを復元する

公開URLで初回起動したら、まず「データのバックアップ」ページから
手順1で書き出したJSONを読み込んで、これまでのデータを復元してください。

## 7. アプリを更新するとき（今後の運用）

このアプリを今後もChatとの会話で改良していく場合：

1. 新しい `index.html` を作ってもらう
2. GitHubリポジトリの `index.html` を新しい内容で上書きアップロード（Commit）
3. **`service-worker.js` の中の `CACHE_VERSION`（例：`"v1"`）を1つ増やして
   一緒にアップロードする**（これを忘れると、インストール済みの端末に
   古いキャッシュのアプリが表示され続けることがあります）
4. GitHub Pagesは自動的に再デプロイされます（数十秒〜数分）
5. インストール済みのアプリ側は、次回起動時（オンライン時）に
   自動的に新しいバージョンに更新されます

## アイコンについて

`icons/` フォルダの4枚は仮のプレースホルダー画像です（「給」の文字のみ）。
正式なロゴ・アイコン画像ができたら、同じファイル名・同じサイズ
（192×192／512×512／512×512／180×180）で差し替えてアップロードし直してください。

## 注意事項

- 国税庁PDFへの自動入力機能（Pyodide＋pypdf）は、初回利用時にネット経由で
  ライブラリを読み込むため、その機能だけはオフラインでは使えません
  （通常の給与計算・年末調整・印刷はオフラインでも動作します）。
- 所得税額の計算ロジックは現時点で「令和8年分」の税制のみに対応しています
  （アプリ内の「税額表について」ページ・年度切り替え時の警告表示を参照）。
