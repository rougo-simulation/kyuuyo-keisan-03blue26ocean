# 収支計算アプリ（PWA / GitHub Pages 公開用）

このフォルダはそのまま新しいGitHubリポジトリの直下（ルート）にアップロードすれば、GitHub Pagesでスマホアプリのように使えるPWA（Progressive Web App）として公開できます。

## ファイル構成

```
.
├── index.html                  アプリ本体（データはブラウザのlocalStorageに保存）
├── manifest.json                PWAの設定ファイル（アプリ名・アイコン・色など）
├── sw.js                        オフラインで開けるようにするサービスワーカー
├── .nojekyll                    GitHub PagesのJekyll変換を無効化
└── icons/
    ├── icon-192.png             仮アイコン（192×192）
    ├── icon-512.png             仮アイコン（512×512）
    ├── icon-512-maskable.png    仮アイコン（Android用セーフゾーン対応）
    └── apple-touch-icon.png     仮アイコン（iOS用 180×180）
```

## 公開手順

1. GitHubで新しいリポジトリを作成する（Public/Privateどちらでも可。Privateの場合はGitHub Pagesが使えるプランか確認してください）。
2. このフォルダの中身一式（index.html, manifest.json, sw.js, .nojekyll, icons/）をリポジトリのルートにそのままアップロード、またはpushする。
3. GitHubのリポジトリ画面で **Settings → Pages** を開く。
4. "Build and deployment" の Source を **Deploy from a branch** にし、Branch を `main`（または使用しているブランチ）・フォルダを `/ (root)` に設定して保存する。
5. 数分待つと `https://ユーザー名.github.io/リポジトリ名/` でアプリが公開されます。

## アイコンの差し替え方法

`icons/` フォルダ内の4つのPNGファイルは仮アイコンです。同じファイル名・同じサイズ（192×192, 512×512, 512×512, 180×180）で正式なアイコン画像を用意し、上書きしてアップロードするだけで反映されます。ファイル名やサイズを変える場合は `manifest.json` と `index.html` 内の該当箇所（`icons/xxx.png` の記述）も合わせて修正してください。

## アプリを更新したとき（重要）

`index.html` の内容を更新して再公開した場合、そのままではユーザーの端末に残っている古いキャッシュが表示され続けることがあります。更新のたびに `sw.js` 内の下記の数字を1つ上げてからアップロードしてください（例: v1 → v2）。

```js
const CACHE_NAME = 'kicho-app-cache-v1';
```

これにより、次回アクセス時に自動的に新しいキャッシュへ切り替わります。

## スマホへの追加（インストール）方法

- **iPhone（Safari）**：サイトを開き、共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：サイトを開き、メニュー →「アプリをインストール」または「ホーム画面に追加」

ホーム画面のアイコンから、ブラウザのアドレスバーなしでアプリのように起動できます。

## データについて

このアプリはサーバーを使用せず、すべてのデータ（事業所・取引先・取引記録）は各端末のブラウザ内（localStorage）に保存されます。端末やブラウザを変えるとデータは引き継がれないため、設定タブの「バックアップを書き出す」を定期的に行い、必要に応じて別端末で「バックアップから復元する」を使ってください。
